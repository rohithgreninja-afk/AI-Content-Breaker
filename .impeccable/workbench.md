## Direction contract

THESIS: A text analysis workbench displays source text beside the report. Results follow the actual compiler stages.

OWN-WORLD: Cool white and gray surfaces, deep blue actions, muted slate text, and an ochre focus accent. The Console view shows the M7 transcript: both verdicts, then the stage output.

FIRST VIEWPORT: A narrow sidebar holds identity, workflow links, and model readiness. The Text analysis heading and M1–M7 rail sit above the source/report split. Analyze text and Humanize text sit below the source field. Empty results state No analysis yet and explain the next action.
